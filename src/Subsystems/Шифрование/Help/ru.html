Модуль «Шифрование» — справочная информация

Модуль «Шифрование»

Предоставляет функции для конфиденциальной обработки данных (симметричное шифрование/расшифровка), генерации криптографических ключей и вычисления хеш-сумм.

Область выполнения: только на сервере (недоступен в мобильном приложении и на клиенте).

Публичное API

  • Обработать(Данные, Ключ) — симметричное шифрование / расшифровка
  • Ключ(УИД) — генерация ключа по уникальному идентификатору
  • Хеш(Данные) — вычисление хеш-суммы

Функция Обработать(Данные, Ключ)

Выполняет симметричную криптографическую обработку переданных двоичных данных. Одна и та же функция используется как для зашифрования, так и для расшифрования: повторный вызов с тем же ключом восстанавливает исходные данные.

Обработать(Данные, Ключ)

Параметры

Имя Тип Описание
Данные ДвоичныеДанные Открытый текст (для шифрования) или шифротекст (для расшифровки).
Ключ ДвоичныеДанные, УникальныйИдентификатор Секретный ключ. Может быть передан непосредственно (как ДвоичныеДанные) или указан как уникальный идентификатор объекта. При передаче УникальныйИдентификатор ключ автоматически вычисляется через функцию Ключ().

Возвращаемое значение

ДвоичныеДанные — результат операции.

Исключения

  • Если Ключ не является типом ДвоичныеДанные или УникальныйИдентификатор, выбрасывается исключение «Ключ может быть типа УникальныйИдентифкатор или ДвоичныеДанные».
  • Если ключ пуст (не заполнен), выбрасывается исключение «Ключ шифрования не может быть пустым значением».
  • При передаче УникальныйИдентификатор могут дополнительно сработать исключения функции Ключ (см. ниже).

Примеры

С ключом, полученным заранее

// Получение ключа
ДвоичныйКлюч = Шифрование.Ключ(УИД);

// Шифрование
ЗашифрованныеДанные = Шифрование.Обработать(ОткрытыеДанные, ДвоичныйКлюч);

// Расшифровка
РасшифрованныеДанные = Шифрование.Обработать(ЗашифрованныеДанные, ДвоичныйКлюч);

С ключом-идентификатором (автоматическая генерация)

// Передаём уникальный идентификатор прямо в вызов
УИД = СсылкаНаОбъект.УникальныйИдентификатор();

// Шифрование – ключ сгенерируется автоматически
ЗашифрованныеДанные = Шифрование.Обработать(ОткрытыеДанные, УИД);

// Расшифровка с тем же УИД (даст тот же ключ)
РасшифрованныеДанные = Шифрование.Обработать(ЗашифрованныеДанные, УИД);

Функция Ключ(УИД)

Формирует криптографический ключ на основе уникального идентификатора объекта метаданных. Ключ вычисляется с использованием криптостойких преобразований и зависит от переданного идентификатора.

Ключ(УИД)

Параметры

Имя Тип Описание
УИД УникальныйИдентификатор Непустой уникальный идентификатор объекта, используемый как соль.

Возвращаемое значение

ДвоичныеДанные — ключ шифрования.

Исключения

  • Если параметр не является заполненным уникальным идентификатором — «Генератор ключа шифрования принимает параметром только значение типа УникальныйИдентификатор».
  • Если отсутствует роль ЧтениеКлючейШифрования — «Нет прав для чтения ключей шифрования (роль: ЧтениеКлючейШифрования)».

Пример

// Получение идентификатора
УИД = СсылкаНаОбъект.УникальныйИдентификатор();

// Генерация ключа
КлючШифрования = Шифрование.Ключ(УИД);

Функция Хеш(Данные)

Вычисляет хеш-сумму переданных данных.

Хеш(Данные)

Параметры

Имя Тип Описание
Данные Строка, ДвоичныеДанные Непустые исходные данные.

Возвращаемое значение

ДвоичныеДанные — хеш-сумма.

Исключения

  • Если тип параметра не Строка и не ДвоичныеДанные — «Генератор хеша принимает параметром только значение типов Строка|ДвоичныеДанные».
  • Если параметр пуст — «Генератор хеша принимает параметром только не пустое значение».

Пример

// Хеширование строки
ХешСтроки = Шифрование.Хеш("Контрольная строка");

// Хеширование двоичных данных
ДвоичныеДанные = ПолучитьДвоичныеДанныеИзСтроки("Данные", "UTF-8");
ХешДвоичных = Шифрование.Хеш(ДвоичныеДанные);

Требования к безопасности

  • Функция Ключ требует наличия роли ЧтениеКлючейШифрования.
  • Функции Обработать и Хеш дополнительных прав не требуют.
  • Все функции предназначены только для серверного кода.

Рекомендации

  1. Для каждого защищаемого объекта генерируйте отдельный ключ (через Ключ) или используйте УИД объекта прямо в вызове Обработать.
  2. Не сохраняйте ключ в открытом виде в информационной базе.
  3. При обработке больших объёмов данных разбивайте их на фрагменты — функция поддерживает последовательную обработку.
  4. Для контроля целостности применяйте Хеш или дополнительные меры.
